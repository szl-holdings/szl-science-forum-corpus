# Science workflow fixtures: provenance

Every file under this directory was hand-authored for the SZL science workflow tests on
2026-10-13. Each one is a synthetic fixture: none describes a real paper, dataset, researcher,
patient or forum post, and none was derived from forum material, a declined fixture or a
withdrawn result.

- `paper_review/`: invented table cells and captions. The PDF digest is the SHA-256 of a fixed
  label string and no PDF exists. Rights are declared as `operator-created` for these invented
  values only.
- `change_recheck/`: invented dependency graphs with sources, analyses, figures and claims.
- `figure_check/`: an invented CSV and figure specification in the canonical figure-data-contract
  format.

These files ship inside the `szl_forum_corpus` package as package data
(`szl_forum_corpus/workflows/fixtures/`), so an installed workbench can load them through its
default path. They moved here unchanged from `tests/fixtures/science_workflows/`; the
`fixture://szl-science-forum-corpus/tests/fixtures/science_workflows/PROVENANCE.md` identifier
inside `paper_review/records.json` is the logical name they were authored with and is kept
byte-for-byte so the fixture inputs and their hand-written expectations stay identical.

The expected results in each `expected*.json` were written by hand from the fixture design before
the workflow code ran against them. They are not generated by the code under test.

These fixtures establish software behaviour only. They are not evidence of scientific accuracy,
researcher benefit or measured time savings.
