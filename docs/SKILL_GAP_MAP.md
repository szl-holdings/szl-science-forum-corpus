# Where the forum pilots extend the existing science skills

This is a source review, not a finding about the forum community. The admitted corpus has one operator-authored topic, so it cannot rank needs or justify training a model. I compared the three proposals in `opportunities.json` with the 30 skill directories in [`szl-holdings/szl-skills` at `b3609d9`](https://github.com/szl-holdings/szl-skills/tree/b3609d9b7d69c14cd1621c91752a8e0233a4ee99) on 2026-10-02. The skill pack's repository tests and release records do not establish Claude Science host registration or measured researcher benefit.

| Proposed pilot | Existing capabilities to reuse | Smallest genuinely new capability | First discriminating test |
| --- | --- | --- | --- |
| `experiment-contract` | [`szl-analysis-plan-audit`](https://github.com/szl-holdings/szl-skills/tree/b3609d9b7d69c14cd1621c91752a8e0233a4ee99/skills/szl-analysis-plan-audit) checks a frozen plan against a run; `szl-negative-control-audit`, `szl-multiplicity-audit`, and `szl-unit-invariants` check narrower declarations. | A prospective design assistant that asks the researcher for an estimand, experimental unit, control, possible falsifier, harm limit, and cheapest decisive measurement, then emits a *draft* plan compatible with the existing audit. It must expose unfilled assumptions and never call a drafted plan preregistered. | Randomize independent researcher tasks between the assistant and a structured plan template. Blind reviewers score preregistered actionability criteria and unsupported claims. |
| `evidence-adjudication` | [`szl-evidence-gate`](https://github.com/szl-holdings/szl-skills/tree/b3609d9b7d69c14cd1621c91752a8e0233a4ee99/skills/szl-evidence-gate) checks artifact presence and digests; `szl-paper-evidence-audit` supplies page/region locators; `szl-refutation-ledger` retains replication outcomes; `szl-retrieval-eval` measures retrieval against judged relevance. | A version-aware, citation-bound *interpretation* layer that classifies a claim as supported, contradicted, insufficient, or outdated, with abstention and a quoted evidence span under its source's rights. Existing integrity checks remain separate from semantic judgment. | Compare with ordinary search plus a citation checklist on a balanced, rights-cleared claim set. Two domain experts adjudicate disagreements; count invented citations as failures. |
| `reproduction-triage` | [`szl-reproducibility-capsule`](https://github.com/szl-holdings/szl-skills/tree/b3609d9b7d69c14cd1621c91752a8e0233a4ee99/skills/szl-reproducibility-capsule) freezes selected bytes; `szl-artifact-lineage` checks declared dataflow digests; `szl-experiment-replay` reruns only a bounded CSV mean; `szl-cross-implementation-check` compares implementations. | A safe triage coordinator that ranks likely data, environment, code, and result discrepancies from those existing receipts, records which checks are still missing, and recommends the next authorized local test. No arbitrary code execution or silent dependency installation. | Compare with a reproduction checklist on independent packages. A researcher verifies the first cause, elapsed time, and whether the top-three ranking included it. |

The first build is now [owner-merged from `szl-skills` PR #46](https://github.com/szl-holdings/szl-skills/pull/46) at source commit `372ff2d4fa72053151aeb77d3e1973090fdc07ab`: `szl-experiment-contract`, a bounded offline helper that reports unfilled design fields and hands off only candidate fields to the frozen-plan audit. It is packaged in a separate design import family so the existing core stays below its 1 MB host limit. Its repository tests and CI checks do not establish Claude Science host registration or researcher benefit. The next step is a small, opt-in development pilot against a structured plan template, followed by a frozen blind scoring rubric, task-family split, exclusions and power calculation before the held-out study. Treat numeric targets in the research protocol as provisional until that work is done.

An approved forum export would support *problem discovery*, not automatic labels or model weights. Keep source revisions, permission records, deduplicated thread families, reviewer disagreements, and removal instructions with every admitted observation. If permissions never extend beyond the operator's own topic, recruit volunteers who explicitly opt in rather than inferring community prevalence from the pilot.
